KEYBOARD SHORTCUTS

Files and figures
  Ctrl+S         Save plot
  Ctrl+Shift+C   Copy figure to clipboard
  F5             Rescan the input folder (top-up run)
  Enter (input)  Rescan too, and remember that folder

Editing
  Ctrl+Z         Undo
  Ctrl+Y         Redo  (also Ctrl+Shift+Z)

Session tabs
  Ctrl+T         New tab (blank session)
  Ctrl+W         Close the current tab
  Ctrl+Tab       Next tab  (Ctrl+Shift+Tab = previous)

The plot, with the mouse
  Click curve    Select it (highlight; defringe-compare target)
  Dbl-click      Solo that curve (again = restore)
  Click legend   Hide / show that trace
  R-click curve  Quick-actions menu: inspect this trace, solo, hide,
                 toggle decompression (D), defringe compare here,
                 show in data table, deselect
  Drag a box     Zoom into it (2D)
  Mouse wheel    Zoom (2D about the cursor; 3D camera)
  Dbl-click pill Reset that pane divider to its default width

The plot, with the keyboard
  Arrow keys     Pan the 2D view / orbit the 3D camera (3 deg a step)
  + / -          Zoom (2D about center; 3D camera)
  0              Fit the 2D view / reset the 3D camera
  1 / 2 / 3 / 4  Stacked & 3D: off / 2D stacked / 3D ridge / 3D shape
  [  /  ]        Previous / next colormap
  Ctrl+R         Reset 3D view

Data
  Ctrl+D         Toggle the raw data table
  Ctrl+C (table) Copy the selected data-table rows

Elsewhere
  Drop a folder  Make it the input folder and rescan (Windows)
  F1             This shortcuts list
  Esc            Close the dialog on top

The tool ignores single keys while you type in a box. Single keys
are the numbers, the brackets, the arrows, +/- and 0. Escape also
cancels a pane-divider drag.
