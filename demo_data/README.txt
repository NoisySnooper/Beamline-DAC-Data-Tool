SPARTA demo dataset
===================

Synthetic, generated by make_demo_data.py.  Not measurement data.

5 series points x 3 channels x 2 grating segments, named in the
22-IR-1 convention the built-in profile reads:

    vis_DEMO_glass_<P>[_bg|_s][_D].<seg>

    no suffix = dark,  _bg = background,  _s = sample
    P uses 'p' for the decimal point: 12p8 = 12.8 GPa
    _D marks the decompression branch (no tag = compression)

    compression    0.0 / 5.2 / 12.8 / 20.1 GPa
    decompression  8.4 GPa, on release from the highest point

Model: a gaussian lamp envelope, an absorption edge that red-shifts
6.4 nm per GPa, and the three etalon tones of one consistent cell:
an n = 1.75 glass plate thinning under load inside an argon-filled
gap that closes with pressure, between diamond anvils.  The sample
channel carries the sample etalon (the strong tone) and the weaker
whole-cell line; the background channel carries the empty-gap
etalon.  The argon index per pressure is the same Ar model the
fringe workbench solves with, so the full loop - detect, assign
roles, Fit peaks, Solve, Record - lands on the ground truth below
(default stack: medium Argon (Dewaele), no layer 2, no clamps).

    P GPa      A      C    iii        t      L    (um)
      0.0 C   32.00  41.40  27.69      18.29  27.69
      5.2 C   30.54  42.89  37.20      17.45  26.13
      8.4 D   27.20  39.22  34.76      15.54  23.77
     12.8 C   28.42  39.82  35.74      16.24  23.85
     20.1 C   26.37  36.51  33.34      15.07  21.66

    A = n_s*t (sample), C = A + n_Ar*(d1+d2) (whole cell),
    iii = n_Ar*L with L = d1+t+d2.  Solve returns n_s = 1.75.

The decompression point does not retrace the compression branch:
its sample path sits 2.45 um below the compression trend at the
same pressure, so 'Only C' / 'Only D' and the Thickness (fringe
n*t) mode both show something real.

Point the Input folder here and press Run.  The interactive tour
(About > Welcome & tour) loads it for you.
